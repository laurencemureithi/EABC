Opsloom patch v4

   - Export XLSX

5. Audit Trail XLSX export outputs the filtered table in structured workbook form.

7. Reports Center and Report History tables now use fixed column widths so headers stay aligned even before any rows exist.
8. Added stronger persistence protection:

   - rolling JSON datastore backup
   - latest SQLite backup copy
